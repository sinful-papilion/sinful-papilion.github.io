# Sinful Papilion

『魔法少女ノ魔女裁判』二次創作サークル Sinful Papilion のサイトです。
本サイトは非公式のファン活動によるもので、公式とは関係ありません。

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | サイト本体 |
| `status.json` | 当日の頒布状況（売り切れ・残りわずか・ひとこと） |
| `.nojekyll` | GitHub Pages でそのまま表示するための空ファイル |

## 当日の頒布状況を更新する

スマホのブラウザからでも更新できます。

1. GitHub でこのリポジトリを開き、`status.json` を開く
2. 右上の鉛筆マーク（Edit this file）を押す
3. `""` の中を書き換える
4. 「Commit changes」を押す

1〜2分ほどでサイトに反映されます。

```json
{
  "dayMode": true,
  "updated": "2026.11.03 13:20",
  "soldout": "アクリルキーホルダー（エマヒロ）\nミニステッカー",
  "few": "トートバッグ",
  "note": "午後も頒布しています！"
}
```

| 項目 | 書き方 |
|---|---|
| `dayMode` | 当日だけ `true` にすると、ページ最上部に「本日開廷」の帯が出ます。終わったら `false` に戻します |
| `updated` | 更新した日時。自由な書き方で大丈夫です |
| `soldout` | 売り切れの品名。複数あるときは `\n` で区切ります |
| `few` | 残りわずかの品名。書き方は売り切れと同じです |
| `note` | 共犯者からのひとこと |

`"` で囲むことと、行末の `,` を消さないことに気をつけてください。崩れたときは、ページは「―」の表示のまま動きます。

## SNS を載せる

`index.html` の中の `var SNS = {` を探し、各共犯者の `""` に URL を入れます。空欄のものは表示されません。
